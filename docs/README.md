## Documentation rules

- Keep current implementation facts separate from target architecture.
- Every capability has one authoritative owner and source of truth.
- Link to implementation docs rather than duplicating them.
- Cross-language Node/Rust contracts must be versioned and tested.
- Preserve upstream license, NOTICE, copyright, and third-party attribution.
- Record superseded plans rather than silently deleting useful history.
